# 💖 Chelsa Jo Agatha - Birthday Website ✨

Website spesial bertema luxury pink yang dibuat khusus untuk merayakan ulang tahun Chelsa Jo Agatha

## 🚀 Live Demo
Akses website live melalui Vercel: [birthday-chelsa.vercel.app](https://birthday-chelsa.vercel.app)

## ✨ Fitur Utama
- 🔐 **Lock Screen**: Halaman proteksi PIN rahasia untuk menjaga privasi sebelum masuk ke website.
- 🏠 **Main Card**: Halaman utama berisi ucapan hangat dan navigasi antar halaman.
- ⏳ **Countdown Timer**: Penghitung waktu mundur real-time menuju hari ulang tahun.
- 🎵 **Music & Playlist**: Pemutar musik latar belakang (Bruno Mars - Just The Way You Are) yang terus menyala mulus saat berpindah halaman.
- 📸 **Memories Gallery**: Kolase galeri foto & video kenangan dengan pop-up lightbox interaktif.

## 🛠️ Teknologi
- HTML5 & CSS3 (Glassmorphism & Responsive Design)
- JavaScript (ES6+)
- Vercel & GitHub
